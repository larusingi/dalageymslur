# Dalageymslur

Static website prototype for a winter vehicle storage business in Iceland.

## Innihald

- Vetrargeymsla fyrir hjólhýsi, fellihýsi og ferðavagna
- Verðreiknivél fyrir skýrt mat á geymsluverði
- Fylgni við grunn upplýsingum fyrir fyrirspurnir og samband

## Keyrsluleiðbeiningar

Opnaðu [index.html](index.html) í vafra eða keyrðu:

```bash
python -m http.server 8000
```

Síðan er hægt að opna http://localhost:8000/.
